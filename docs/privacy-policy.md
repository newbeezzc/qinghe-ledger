# 青禾记账 隐私政策

> 备案/上架提示：如提交 APP 备案或应用商店，请把「运营者」替换为你的实名信息，并补充可联系的邮箱；公开使用时可保留 GitHub 联系方式。

生效日期：2026-10-26

青禾记账（包名 `com.qinghe.ledger`，以下简称「本应用」）是一款本地优先的记账工具。本政策说明本应用如何处理你的信息。

## 1. 我们收集哪些信息

本应用不要求注册账号，不收集手机号、身份证、位置、通讯录、相册或设备标识，也不接入广告或统计分析 SDK。

你主动录入或由本应用自动识别的账目、分类、账户、预算、备注等信息，仅保存在你设备上的应用私有数据库中。

## 2. 权限及用途

| 权限 | 用途 | 数据处理 |
|---|---|---|
| 通知使用权 | 读取微信「微信支付」和支付宝的支付通知，用于自动记账 | 仅在本机解析，不保存通知原文，不上传 |
| 无障碍服务 | 读取微信/支付宝的支付成功页或单笔账单详情页，用于自动记账 | 仅在本机解析页面文本，不做 OCR，不上传 |
| 悬浮窗（显示在其他应用上层） | 自动记账后显示金额、分类和「修改/取消记账」按钮 | 仅在本机显示 |
| 通知权限 | 自动记账后的提醒 | 仅在本机显示 |
| 安装未知应用 | 安装你确认下载的应用更新 | 仅在本机使用 |
| 网络权限 | 检查并下载 GitHub Release 更新 | 只访问 GitHub，不上传账目、通知或页面文本 |

通知和无障碍权限都需要你在系统设置中手动开启；你可以随时关闭，关闭后本应用将无法自动记账，但仍可手动记账。

## 3. 联网与第三方

本应用唯一的联网用途是检查/下载更新，访问 GitHub（`api.github.com`、`github.com`、`release-assets.githubusercontent.com`）。请求中只包含应用版本等更新检查所需信息，不包含你的账目、通知内容或页面文本。

GitHub 的隐私政策见：https://docs.github.com/site-policy/privacy-policies/github-privacy-statement

本应用不向任何第三方出售、出租或共享你的账目信息。

## 4. 数据存储与删除

- 账目数据保存在本机应用私有目录的 SQLite 数据库中；
- 你可以在应用内编辑或删除单条账目、分类、账户和规则；
- 卸载本应用会删除应用私有数据（系统备份功能开启时，可能由系统备份到你的个人云空间，具体由系统设置决定）；
- 本应用不保留服务器端副本，因此没有「云端注销账号」流程。

## 5. 数据安全

本应用不把账目上传到服务器，数据安全主要取决于你的设备锁屏、系统账号和备份设置。请妥善保管设备，并注意系统备份是否包含应用数据。

## 6. 未成年人

本应用不是面向 14 周岁以下儿童设计的产品，也不会主动收集未成年人的个人信息。

## 7. 政策更新

如果本应用的功能或数据处理方式发生变化，我们会更新本政策并在应用内或项目仓库中说明。重大变化会在更新说明中提示。
