### 0.1 ✅ 华为禁止应用内自行下载安装更新（审核指南 3.9）

## 3. 审核风险与应对话术

### 3.1 无障碍服务（最高风险）

华为对无障碍权限审核很严。提交时在备注/自测文件中明确：

- 无障碍服务**只**读取微信、支付宝、抖音、美团的**支付成功页 / 单笔账单详情页**；
- 不读取聊天内容、不读取其他应用、不做 OCR；
- 仅在本机解析，不保存页面文本、不上传；
- 用户必须在系统设置中手动开启，可随时关闭；
- 关闭后手动记账完全可用。

如果审核员仍要求说明，可在「应用审核信息 → 备注」补充上述内容（已包含在 `审核备注.txt` 中）。

### 3.2 通知使用权

同上：只读取上述应用的支付通知，仅本机解析，不保存通知原文、不上传。

### 3.3 悬浮窗

仅用于付款后显示半屏记账确认卡片；不遮挡系统界面、不劫持其他应用；用户可拒绝授权，拒绝后回退到通知栏提醒。

### 3.4 应用内更新（必须处理）

见 0.1。**不要**在华为渠道包里保留「检查更新 / 下载 APK / 安装未知应用」；审核指南 3.9 明确禁止。华为渠道包只保留「请通过华为应用市场更新」的提示。

### 3.5 商标与关联关系

应用介绍和截图里会出现「微信」「支付宝」「抖音」「美团」。建议在应用介绍末尾保留免责声明（已写入 `应用介绍.txt`）：

> 本应用与腾讯、阿里巴巴、字节跳动、美团无关联；相关名称和商标归其各自权利人所有。

不要在图标、应用名、截图中使用这些平台的官方 logo。

### 3.6 隐私政策链接

华为会实际打开隐私政策 URL 检查。使用隐私托管后，务必确认链接可匿名访问、内容包含权限说明和联系方式。

## 5. 签名决策（需要你确认）

当前 release APK 用本机 debug keystore 签名（`CN=Android Debug`），SHA-256：

```
4a3bcbb12b56a1092c7d981a5a3ff407d03dfbcbddecac77e0ba851e3f35cbf0
```

三个选项：

| 方案 | 优点 | 代价 |
|---|---|---|
| A. 继续用 debug keystore | 现有 GitHub/Gitee 用户可无缝升级；改动最小 | 证书名 `Android Debug` 不够正式，个别审核员可能质疑；keystore 丢失后无法更新 |
| B. 新建正式 release keystore，只签华为包 | 华为包更规范；GitHub 包不受影响 | 同一包名两个签名，用户不能跨渠道覆盖安装；需长期备份 keystore |
| C. 新建正式 release keystore，所有渠道统一 | 最规范，长期可维护 | 现有用户必须卸载重装（本地账目会丢，除非先导出/备份）；与 CLAUDE.md 的签名警告冲突 |

**建议 B**：华为渠道单独用正式 keystore，GitHub/Gitee 继续用现有 debug keystore。两个渠道本就因为华为重新签名而无法互相覆盖，分开签名不影响现有用户。若你更看重统一，选 C，但必须先提醒现有用户备份。

> 华为应用市场会对上传的 APK 重新签名，因此华为包安装后的证书与上传包不同；这也是华为渠道包必须移除自更新的原因之一。

## 6. 附录 A：1080×1920 截图重拍步骤（已完成，留作以后换版本时参考）

1. 启动现有 AVD（`D:\Software\android-avd\qinghe35`）：
   ```bash
   export ANDROID_HOME="D:/Software/android-sdk"
   "$ANDROID_HOME/emulator/emulator.exe" -avd qinghe35 -no-snapshot-load &
   "$ANDROID_HOME/platform-tools/adb.exe" wait-for-device
   ```
2. 把分辨率改成 9:16（不改变 UI 密度）：
   ```bash
   "$ANDROID_HOME/platform-tools/adb.exe" shell wm size 1080x1920
   "$ANDROID_HOME/platform-tools/adb.exe" shell wm density 440
   ```
3. 安装华为渠道包：
   ```bash
   "$ANDROID_HOME/platform-tools/adb.exe" install -r dist/qinghe-1.0.22-huawei.apk
   ```
4. 逐页截图（`exec-out` 避免 Windows 换行破坏 PNG）：
   ```bash
   "$ANDROID_HOME/platform-tools/adb.exe" exec-out screencap -p > docs/filing/huawei/screenshots/01-home.png
   ```
   建议顺序：明细首页 → 记一笔 → 统计 → 预算 → 我的 → 自动记账确认卡片。
5. 检查每张图：`python -c "from PIL import Image; print(Image.open('...').size)"` 必须是 `(1080, 1920)`；截图里不能有权限弹窗、通知栏测试账号、其他市场 logo。
6. 拍完后恢复模拟器分辨率：
   ```bash
   "$ANDROID_HOME/platform-tools/adb.exe" shell wm size reset
   "$ANDROID_HOME/platform-tools/adb.exe" shell wm density reset
   ```

> 如果模拟器启动后状态栏时间、电量等元素不完整，可以接受；不要为了画面好看去 P 图或加设备边框。
