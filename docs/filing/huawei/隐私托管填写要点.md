# 华为协议服务 · 隐私托管填写要点

> 用途：在 AGC「协议服务」里生成《隐私政策》《用户协议》时对照填写。
> 原则：华为渠道包（v1.0.22-huawei）不申请网络权限、不上传任何数据，所有解析都在本机完成。

## 1. 应用基本信息

| 字段 | 内容 |
|---|---|
| 应用名称 | 青禾自动记账 |
| 包名 | `com.qinghe.ledger` |
| 开发者/运营者 | 你的实名姓名或主体名称 |
| 联系邮箱 | 你的常用邮箱 |
| 联系渠道 | https://github.com/newbeezzc/qinghe-ledger/issues |
| 生效日期 | 首次提交日期（如 2026-11-XX） |
| 更新日期 | 同上 |

## 2. 是否收集个人信息

**否**。本应用不要求注册账号，不收集手机号、身份证号、位置、通讯录、相册、麦克风、相机、短信、设备标识（IMEI/OAID/Android ID）、应用使用数据或崩溃日志。

账目、分类、账户、预算、规则只保存在设备本地的应用私有数据库中；开发者无法访问，也不会上传。

## 3. 权限清单（隐私政策里逐项列出）

| 权限 | 用途 | 数据处理 |
|---|---|---|
| 通知使用权 | 读取微信支付、支付宝、抖音、美团的支付通知，用于自动记账 | 仅在本机解析金额、商户、时间；不保存通知原文，不上传 |
| 无障碍服务 | 读取微信、支付宝、抖音、美团的支付成功页或单笔账单详情页 | 仅在本机解析页面文本；不做 OCR，不读取聊天内容，不读取其他应用，不保存、不上传 |
| 悬浮窗（显示在其他应用上层） | 自动记账后显示半屏确认卡片，可修改或取消 | 仅在本机显示 |
| 通知权限 | 自动记账结果提醒 | 仅在本机显示 |
| 网络权限 | **华为渠道包不申请**；其他分发渠道仅用于检查/下载应用更新 | 不上传账目、通知或页面文本 |

补充说明：

- 以上权限均需用户在系统设置中手动开启，可随时关闭；
- 关闭通知使用权/无障碍服务后，自动记账停止，手动记账不受影响；
- 应用不会在后台读取与支付无关的通知或页面。

## 4. 第三方共享 / SDK

- 不接入广告 SDK；
- 不接入统计分析 SDK；
- 不接入崩溃收集 SDK；
- 不向任何第三方出售、出租或共享用户数据；
- 华为渠道包无网络请求，不存在数据出境。

## 5. 数据存储与删除

- 账目数据保存在设备本地的 SQLite 数据库；
- 用户可在应用内编辑/删除单条账目、分类、账户、预算和规则；
- 卸载应用会删除应用私有数据（系统备份功能开启时，可能由系统备份到用户个人云空间，具体由系统设置决定）；
- 开发者不保留服务器端副本，因此没有「云端注销账号」流程。

## 6. 未成年人

本应用不是面向 14 周岁以下儿童设计的产品，也不会主动收集未成年人的个人信息。若未成年人使用，应在监护人指导下使用。

## 7. 政策更新

功能或数据处理方式变化时，会更新隐私政策并在应用市场详情页/应用内说明；重大变化会在版本更新说明中提示。

## 8. 用户协议要点

- 本应用为本地记账工具，不提供支付、转账、借贷、理财、征信等金融服务；
- 自动识别结果仅供参考，不保证 100% 准确，重要账目以各平台官方账单为准；
- 用户应妥善保管设备；因设备丢失、系统备份、卸载等造成的数据丢失，开发者不承担赔偿责任；
- 应用与腾讯、阿里巴巴、字节跳动、美团无关联，相关商标归其权利人所有；
- 应用完全免费，无内购、无广告。

## 9. 生成后要回填的地方

1. AGC「隐私声明 → 隐私政策」选择刚生成的链接；
2. AGC「隐私声明 → 用户协议」选择刚生成的链接；
3. 把隐私政策 URL 发给开发侧，加到 App「我的 → 关于与更新 → 隐私政策」。
