# 青禾自动记账 · 审核自测说明

## 一、应用信息

| 项目 | 内容 |
|---|---|
| 应用名称 | 青禾自动记账 |
| 包名 | com.qinghe.ledger |
| 版本 | 1.0.22（versionCode 23） |
| 安装包 | qinghe-1.0.22-huawei.apk |
| 支持系统 | Android 8.0（API 26）及以上 |
| 登录要求 | 无账号、无登录，安装后直接使用 |
| 网络要求 | 华为渠道版本不申请网络权限，全部功能离线可用 |

## 二、测试环境

- 建议使用 Android 8.0 及以上真机或模拟器；
- 自动记账部分需要手机已安装微信或支付宝，并有一个可打开的支付账单（可以是历史账单详情页，不需要真实付款）；
- 首次启动不需要任何权限即可完成手动记账。

## 三、基础功能自测

### 1. 安装与启动

1. 安装 APK，桌面图标名称为「青禾自动记账」；
2. 打开应用，进入「明细」首页，底部有「明细 / 统计 / 预算 / 我的」四个标签；
3. 首次启动不弹隐私弹窗、不要求登录，可直接使用。

### 2. 手动记一笔

1. 点击首页右下角「+」或列表中的「记一笔」；
2. 输入金额（例如 12.50）；
3. 选择类型「支出」；
4. 选择大类（如「餐饮」）和小类（如「午餐」）；
5. 选择账户（如「现金」）；
6. 可修改日期时间和备注；
7. 点「保存」，返回首页，账目出现在当天分组中，月度支出汇总同步增加。

### 3. 明细编辑与删除

1. 点击一条账目进入编辑页，修改金额或分类后保存，首页同步更新；
2. 长按一条账目，弹出删除确认，确认后账目消失；
3. 切换月份（左右箭头），可查看其他月份账目。

### 4. 统计

1. 底部切到「统计」；
2. 可切换「支出 / 收入」；
3. 页面显示分类占比环图、分类金额列表和每日柱状图；
4. 切换月份，数据随之变化。

### 5. 预算

1. 底部切到「预算」；
2. 首次进入可设置月度预算（例如 5000 元）；
3. 页面显示剩余可用、已用、预算、日均可用；
4. 下方显示分类预算进度；记一笔支出后进度同步变化。

### 6. 账户

1. 「我的」→「账本」→「账户管理」；
2. 可新增、编辑、删除账户；
3. 账户余额随账目自动计算；
4. 转账记录会同时影响转出和转入账户。

### 7. 分类

1. 「我的」→「账本」→「分类管理」；
2. 可新增/编辑/删除大类和小类；
3. 记账页的分类选择与分类管理保持同步。

## 四、自动记账（可选功能）自测

> 自动记账不是核心记账功能的必要条件；不开启任何权限也能正常手动记账。

### 1. 开启权限（华为/EMUI/HarmonyOS 路径）

| 权限 | 路径 |
|---|---|
| 通知使用权 | 设置 → 通知和状态栏 → 通知使用权 → 青禾自动记账 → 允许 |
| 无障碍服务 | 设置 → 辅助功能 → 无障碍 → 已下载的服务 → 青禾自动记账 → 开启 |
| 悬浮窗 | 设置 → 应用 → 应用管理 → 青禾自动记账 → 权限 → 悬浮窗 → 允许（或：设置 → 应用 → 特殊访问权限 → 显示在其他应用上层） |
| 通知权限 | 设置 → 通知 → 青禾自动记账 → 允许通知 |

也可以从应用内「我的 → 自动记账设置」逐项跳转开启。

### 2. 页面识别路径（推荐审核员使用）

1. 打开微信 → 我 → 服务 → 钱包 → 账单，或支付宝 → 我的 → 账单；
2. 打开任意一笔**已完成**的账单详情页（包含金额、商户、交易单号/订单号、支付时间）；
3. 返回桌面再切回应用，或在账单页停留 2–4 秒；
4. 应用识别成功后，会在当前页面弹出不超过半屏的「自动记账」确认卡片，金额、分类、账户、备注、支付时间已填好；
5. 点右下角「确认」保存，或点「取消」删除这笔自动账目并返回原应用；
6. 同一笔账单重复打开不会重复入账（去重窗口为支付时间 ±120 秒）。

### 3. 通知识别路径

1. 保持通知使用权开启；
2. 使用微信/支付宝完成一笔小额支付（或让同事向测试账号转账 0.01 元）；
3. 支付通知到达后，应用在本机解析并生成账目；
4. 若已授予悬浮窗权限，会直接弹出半屏确认卡片；未授予时回退到通知栏提醒。

### 4. 验证「不读取聊天内容」

1. 在微信聊天窗口发送包含金额的文字（如「今天花了 100 元」）；
2. 应用不会因此生成账目；
3. 聊天页面不会被识别为支付页面。

## 五、隐私与离线验证

1. 打开飞行模式，关闭 Wi-Fi 和移动数据；
2. 手动记账、统计、预算、账户、分类、明细全部可用；
3. 应用不会请求网络，也不会弹出联网失败提示；
4. 在系统「应用信息 → 流量使用」中确认应用无网络流量；
5. 应用内「我的」页面提供隐私政策入口，可查看完整说明。

## 六、已知限制（如实说明）

- 自动识别依赖微信、支付宝、抖音、美团的页面和通知结构，不保证 100% 准确；
- 银行 App、云闪付、红包、部分小程序支付可能无法识别；
- 相关应用改版后，识别可能暂时失效，需要后续版本适配；
- 自动记账为可选功能，关闭权限后手动记账不受影响。

## 七、审核备注

本应用无需登录，无测试账号。核心记账功能无需任何权限即可使用；自动记账需用户手动开启通知使用权或无障碍服务并授予悬浮窗权限。应用为单机工具，不提供支付、借贷、理财等金融服务，不上传账目、通知或页面文本。
