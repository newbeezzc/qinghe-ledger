## 二、功能描述

### 短版（约 60 字，适合“应用简介”）

> 青禾记账是一款本地优先的个人记账工具，支持手动记账、两级分类、账户、预算和统计，并可在本机自动识别微信/支付宝支付生成账目。所有数据仅保存在本机，不上传服务器。

### 详细版（适合“功能描述”）

> 青禾记账是一款本地优先的个人记账应用。支持支出、收入、转账记录，提供大类-小类两级分类、账户管理、月度统计图表、预算和自动分类规则。用户手动开启通知使用权或无障碍服务后，应用可在本机读取微信支付、支付宝的支付成功页或单笔账单详情，自动生成账目，并可在悬浮卡片上修改或取消。账目仅保存在本机数据库，不收集个人信息，不上传服务器；联网仅用于检查/下载 GitHub Release 更新。

### 服务内容补充（如表单要求）

> 个人本地记账工具，不提供交易、支付、借贷、理财、征信等金融服务，不提供用户发布、社交、直播、新闻资讯等内容服务；无自建服务器，联网仅用于从 GitHub 检查/下载应用更新。

## 五、填写注意事项

1. **应用分类建议选「工具类 / 实用工具」**，不要选「金融理财」——本应用不提供支付、借贷、理财、征信等金融服务，选了金融类可能被要求补充金融资质。
2. **月活/注册用户按实际填写**：本应用没有账号体系，注册用户总量为 0；个人自用月活填 1。不要虚报。
3. **前置许可选「无」**：不涉及新闻、出版、教育、医疗保健、药品和医疗器械、金融等需要前置审批的内容。
4. **隐私政策**：`docs/privacy-policy.md` 目前是草稿，必须先把 `[个人开发者名称]`、`[联系邮箱]` 换成真实信息再提交；如果表单要求可访问的网页，GitHub 的 blob 链接通常可用，若被拒我可以帮你开 GitHub Pages。
5. **服务器/域名**：本应用没有自建服务器，更新检查访问 GitHub。若表单必填服务器或域名，按实际情况说明“无自建服务器，仅访问 GitHub 更新源”，并咨询接入商是否接受。
6. **备案通过后**：把备案编号发给我，我可以在「我的 → 关于」增加备案编号展示，并发布一个新版本。备案信息与包名、签名相关，后续不要随意更换签名。

## 六、当前签名说明

当前 release APK 使用本机 debug keystore 签名（`CN=Android Debug`），适合个人安装和备案；如果将来公开上架并更换正式签名，已安装用户无法覆盖升级，且备案信息可能需要同步更新。更换签名前先确认是否需要卸载重装。
