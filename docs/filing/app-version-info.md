## 功能描述（修改了什么功能）

### 短版（一段话）

> 本次版本优化自动记账分类：结合商户名、商品说明、平台信息和支付时间，优先归入对应小类；自动记账悬浮窗显示时间调整为 5 秒；移除分类管理页的旧版说明卡片，并更新自动分类规则说明。

### 列表版

1. 自动分类升级：先匹配用户保存的规则，再根据商户名、商品说明中的具体关键词归类；平台关键词只确定大类，命中后继续细化到小类；餐饮按支付时间判断早餐/午餐/晚餐。
2. 自动记账悬浮窗显示时间由 3 秒调整为 5 秒。
3. 删除分类管理页底部残留的旧版更新说明卡片，更新自动分类规则页的说明文案。

### 如果表单要「应用整体功能」

> 青禾记账是一款本地优先的个人记账应用。支持支出、收入、转账记录，提供大类-小类两级分类、账户管理、月度统计图表、预算和自动分类规则。用户手动开启通知使用权或无障碍服务后，应用可在本机读取微信支付、支付宝的支付成功页或单笔账单详情，自动生成账目，并可在悬浮卡片上修改或取消。账目仅保存在本机数据库，不收集个人信息，不上传服务器；联网仅用于检查/下载 GitHub Release 更新。
