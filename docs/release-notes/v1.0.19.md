# v1.0.19

- 大幅减少自动记账误报，尤其是支付宝：先确认页面是支付成功页或单笔账单详情页，再读取金额。首页、余额 / 额度 / 收益、账单列表、还款页等普通含数字页面不再触发。
- 金额识别更准确：优先读取「实付 / 实收 / 支付金额 / 交易金额」等字段，忽略余额、额度、优惠等非支付数字；优惠在前、实付在后时也能取对金额。
- 旧账单识别恢复：打开旧账单时会先按金额和支付时间查重，账本里已有这一笔就跳过；没有才会按历史支付时间入账。手工记过的同一笔也算重复。
- 更新下载更稳定：GitHub 直连失败或中断时，自动切换 ghfast / gh-proxy / ghproxy 镜像，并支持 HTTP 断点续传。
- 新增「我的 → 关于与更新 → 更新镜像」：可填写自己的代理前缀或 `{url}` 模板；留空使用内置镜像。安装前仍会校验包名、版本和签名。
- 检查更新失败后不再把自动检查推迟 24 小时，下次启动会重试。
- 同步更新使用说明、隐私政策和故障排查文档。
