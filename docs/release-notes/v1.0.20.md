# v1.0.20

- 默认优先从 **Gitee Release** 检查更新，国内网络访问更稳定；Gitee 不可用、没有 Release、没有 APK 或下载失败时，自动回退 GitHub。
- 「我的 → 关于与更新」新增 Gitee 更新源设置（默认 `newbeezzc/qinghe-ledger`，清空即停用），原 GitHub 更新源改为备用源。
- 如果 Gitee 版本比 GitHub 旧，仍会检查 GitHub 并提示更新，不会漏掉新版本。
- 下载继续支持 GitHub 镜像和 HTTP 断点续传；Gitee 下载失败时尝试同版本的 GitHub 地址。
- 发布脚本支持同步 Gitee：检测到 `.gitee-token` 和 `gitee` remote 时，GitHub 发布完成后自动创建 Gitee Release 并上传 APK。
- 同步更新隐私政策、故障排查和使用说明。
