# 青禾记账 · App 备案说明

> 本文是技术/流程说明，不构成法律意见。各地通信管理局和接入商的要求可能不同，最终以接入商和管局答复为准。

## 1. 「应用备案状态未知」是什么

这是国产手机安装器（小米/Redmi、华为/荣耀、OPPO/vivo 等）在安装第三方 APK 时，按工信部《关于开展移动互联网应用程序备案工作的通知》（工信部信管〔2023〕105号）去查询备案库的结果。

- 查询不到时显示「应用备案状态未知 / 应用未备案」；
- 单机应用、境外应用、个人小工具、未上架应用商店的 APK 都会触发；
- 它**不是病毒或安全检测结论**，不影响 APK 本身的功能；
- 点「继续安装 / 仍要安装 / 已了解风险」即可完成安装。

## 2. 这个 App 需要备案吗

分两种情况：

### 个人自用（ sideload / 自己的手机）

- 不通过应用商店分发，不需要为了安装去备案；
- 每次安装或应用内更新，系统安装器仍会弹一次提示，这是安装器的行为，不是 App 能控制的；
- 点继续安装即可，账目和功能不受影响。

### 公开分发 / 上架国内应用商店

- 国内应用商店和分发平台会校验备案信息，通常要求提供备案号；
- **纯单机、完全离线**的工具类 App，一般可按「单机应用」处理，不需要 APP 备案；
- 但本 App 有一个联网功能：检查/下载 GitHub Release 更新。它不提供面向公众的互联网信息服务，但部分商店会把「核心功能需要访问公共互联网」视为非单机，从而要求备案。**边界情况请以商店审核和接入商答复为准**；
- 若上架商店，还通常需要软件著作权（软著）、隐私政策、应用截图等。

工信部通知的核心要求：在境内从事互联网信息服务的 APP 主办者应履行备案；通过接入服务提供者或 APP 分发平台提交；材料包括备案登记表、承诺书等；管局一般在 20 个工作日内完成审核；备案后应在 App 显著位置展示备案编号。

## 3. 如果决定备案：个人主体的现实门槛

个人可以备案，但通常需要：

- 实名认证的账号（身份证、手机号、邮箱，部分环节需要人脸识别）；
- **一个已完成 ICP 备案的域名 + 中国大陆境内的服务器/云资源**（多数云厂商的 APP 备案以此为前提）；
- 或通过国内应用商店的开发者后台，在提交应用时走商店的备案通道（是否允许「单机应用」免备案由商店判定）；
- App 信息：名称、包名、签名、版本、图标、功能说明、隐私政策 URL；
- 备案登记表、承诺书等材料；
- 管局审核通常 1–20 个工作日，通过后获得备案编号。

**我无法替你完成备案提交**：备案需要你的实名身份、人脸/短信验证、对材料真实性的法律责任，以及接入商/商店账号授权；这些不能由我代办，也不应该由我冒用你的身份提交。

## 5. 不备案时怎么正常安装

安装页出现提示后：

| 手机 | 操作 |
|---|---|
| 小米 / Redmi（HyperOS/MIUI） | 点「已了解此应用存在风险」→「仍然安装」；或在 设置 → 应用设置 → 应用管理 → 右上角设置 中关闭「应用安全检测」/「纯净模式」 |
| 华为 / 荣耀 | 设置 → 系统和更新 → 纯净模式 → 关闭「增强防护」，再安装 |
| OPPO / vivo / 一加 | 点「继续安装」，勾选「已了解风险」 |
| 通用 | 电脑执行 `adb install -r dist/qinghe-1.0.13.apk`；或开飞行模式安装（部分机型可跳过联网校验） |

注意：每次应用内更新都会重新经过系统安装器，因此提示可能再次出现，这是正常现象。

## 6. 拿到备案号之后

备案通过后，可以把备案编号写进 App 的「我的 → 关于」页面（例如「京ICP备xxxxxxxx号-2A」）。需要时告诉我编号，我可以：

- 在设置页增加备案编号展示；
- 更新隐私政策中的运营者信息；
- 重新打包并发布一个版本。
