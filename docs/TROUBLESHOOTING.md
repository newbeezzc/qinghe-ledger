# 青禾记账 · 自动记账排查指南

本文覆盖自动记账的开启步骤、常见失败原因和排查方法。自动记账是可选的；不开启时手动记账不受影响。

## 1. 开启自动记账

进入「我的 → 自动记账设置」：

1. **通知监听** → 系统「通知使用权」→ 找到「青禾自动记账」并开启。
2. **支付页面识别**（可选）→ 系统「无障碍」→ 找到「青禾支付页面识别」并开启。
3. **悬浮窗提醒** → 允许青禾「显示在其他应用上层」；没有权限时会回退到通知栏。
4. 确认「通知自动记账」「页面自动记账」「自动记账后提醒」三个开关已打开。
5. Android 13 及以上首次启动会请求通知权限；拒绝不影响记账，只是提醒不可用。

支付后，屏幕下方会出现「已自动记账」卡片，显示金额、分类、账户和时间。可以点「修改」打开编辑页，点「取消记账」删除这笔账；卡片 5 秒后自动关闭。没有悬浮窗权限时改为发送高优先级通知。

## 2. 真机使用注意

- 微信「微信支付」服务号通知、支付宝通知需要允许显示；静音、折叠不影响监听。
- 小米 / 澎湃、OPPO / ColorOS、vivo / OriginOS 等系统建议允许青禾自启动、关闭电池优化，避免服务被回收。
- 覆盖安装新版本后，部分系统会重置「通知使用权」「无障碍」「悬浮窗」授权，需要重新打开。
- 自动记账依赖通知或页面中的金额文本；红包、部分小程序支付、银行直连支付可能识别不到。

## 3. 支付成功页没有入账

页面识别只处理两类页面：

1. **支付成功 / 付款成功页**：需要成功标题、金额，以及一个上下文标记（完成、支付方式、零钱、余额宝、查看账单等）。
2. **单笔账单详情页**：需要交易单号、付款方式、当前状态等多个标记。

账单列表、聊天窗口、月账单汇总不会逐笔记录。如果支付成功页没有触发：

- 确认「支付页面识别」权限和「页面自动记账」开关都已打开；
- 打开「自动记账设置 → 识别诊断」，查看最近的页面文本和失败原因；
- 如果原因是「支付成功页标记不足」，把该页文本复制反馈，方便补充规则；
- 部分系统支付保护会拦截无障碍读取，见第 5 节。

## 4. 微信账单不识别 / 没有提醒

1. **页面识别只支持单笔账单详情页**：在微信「我 → 服务 → 钱包 → 账单」里点开某一笔交易，进入「账单详情」后再看；停留在账单列表不会逐笔记录。
2. 打开「自动记账设置 → 识别诊断」，先看两个累计计数：
   - 「累计微信/支付宝页面事件」有增长，但页面文本为空或提示「页面文本太少」→ 可能是微信 8.0.55–8.0.58 的无障碍 UI 树异常、WebView 延迟渲染（应用会自动重试 4 次）、系统支付保护或安全窗口。
   - 「累计微信/支付宝通知」一直为 0 → 通知监听没有收到微信/支付宝的任何通知。先确认微信/支付宝的系统通知权限；再让朋友发一条普通微信消息测试（普通消息也会被计数，只是识别为「不是支付类通知」）。如果普通消息也不计数，说明系统/微信没有把通知交给监听服务。
   - 通知计数在增长，但打开旧账单时「最近支付通知」为空是正常的：打开账单不会产生新通知，只有真实支付/收款时才会。
3. 如果记账成功但没有提醒：
   - 在「自动记账设置 → 系统通知权限」确认已开启，并进入系统通知设置确认「自动记账提醒」渠道未被静音；
   - 首页出现「开启自动记账提醒」横幅时，点它直接跳转通知设置。

## 5. 页面有事件但文本为空

按优先级排查：

1. **微信 8.0.55–8.0.58 的已知无障碍异常**：这些版本会返回错乱/空的 UI 树。诊断页会显示微信版本并提示；可升级微信，或临时回退到 8.0.54 再试。
2. **WebView / 列表延迟渲染或节点过深**：应用已增加 0 / 0.8 / 2 / 3.5 秒四次重试、`findAccessibilityNodeInfosByText` 关键词搜索和父节点回溯。安装最新版后重新打开同一笔账单详情页再观察。
3. **华为 / 荣耀「支付保护中心」深度隔离**：部分机型/版本会拦截第三方无障碍读取；可关闭微信 / 支付宝的深度保护后再试。
4. **页面使用安全窗口 / 自绘视图**：非 OCR 方案无法读取，只能依赖通知监听或手动记账。

华为 / 荣耀关闭支付保护的路径（可选排查）：

- 桌面下拉搜索「支付保护中心」→ 右上角设置 → 深度隔离 / 深度保护 → 关闭微信、支付宝。
- 或 设置 → 安全 → 支付保护中心 → 关闭对应应用的保护。
- 或在设置中搜索「支付保护 / 安全支付 / 支付保险箱」。

关闭后重新打开微信「账单详情」页，再回「识别诊断」查看页面文本。

## 6. 识别范围与边界

- 微信：标题或内容包含「微信支付 / 微信支付凭证 / 交易单号 / 服务通知」的支付通知。
- 支付宝：标题或内容包含「支付宝 / 支付助手 / 交易单号 / 交易提醒 / 支付提醒 / 服务提醒」的支付通知。
- 通知内容必须同时出现支付类动词（支付成功、付款、扣款、收款到账、退款等）和明确金额（`¥12.34`、`12.34元` 或账单详情中的独立金额）。
- 月度账单、还款提醒、额度提醒等会被主动排除。
- 聊天窗口会被排除，避免把聊天里的「支付成功 ¥25」误记成账。
- 自动账目的时间优先取页面上的「支付时间 / 付款时间 / 交易时间 / 创建时间」；通知记录使用系统通知的 postTime；都取不到时才使用当前时间。
- 自动账目的备注只写入提取到的商户名；提取不到商户时备注留空，不会把「返回 / 账单详情」等页面 UI 文本写进备注。
- 自动识别不保证 100% 准确。部分银行 App、云闪付、小程序内支付可能无法识别；请以微信 / 支付宝官方账单为准。

## 7. 更新失败

- 更新 APK 必须与当前安装包使用同一签名，签名不一致会被系统拒绝安装。
- 从 GitHub 下载失败时，应用会先尝试 API 附件通道（`api.github.com` / `release-assets.githubusercontent.com`），再回退 `github.com` 下载地址。
- 首次安装更新需要允许青禾「安装未知应用」，应用会跳到对应系统设置。
- 更新源仓库必须是公开的；API 未登录每小时最多 60 次，普通使用足够。
